# Lab_show

## التحكم بمفاتيح جهاز الطالب

التطبيق برنامج سطح مكتب Electron؛ واجهته المحلية تعمل داخل نافذة التطبيق ولا
تُنشر كموقع. عند التشغيل اختر «الطالب: مشاركة الشاشة» لإدخال رمز الأستاذ، أو
«الأستاذ: استقبال شاشة» لإنشاء رمز محلي واستقبال البث.
لا تفتح `renderer/index.html` مباشرةً في Chrome أو أي متصفح؛ ملف الواجهة يحتاج
خدمات Electron المحلية. للتطوير شغّل `npm start`، وللاستخدام العادي شغّل تطبيق
Lab show المثبّت من قائمة Start.

تظهر لوحة المفاتيح في نافذة الأستاذ أثناء بث الشاشة. تبقى معطلة حتى يضغط الطالب
«السماح للأستاذ بالتحكم بالمفاتيح» من التطبيق أو قائمة شريط النظام، ويمكنه إيقاف
السماح في أي وقت. يُلغى السماح عند إيقاف البث أو إيقافه مؤقتاً.

تُرسل مفاتيح التنقل الأساسية فقط (الأسهم وEnter وSpace وEscape وTab وHome/End
وPage Up/Down)، وبحد أقصى 12 ضغطة في الثانية. لا يدعم التطبيق إرسال نصوص أو
اختصارات نظام أو أوامر. لا تُقبل رسائل التحكم إلا من جلسة الأستاذ المحلية، ومن
جهاز الطالب الموجود على الشبكة الفرعية المحلية نفسها.
