# Lab show

تطبيق سطح مكتب يعمل داخل شبكة المختبر المحلية لمشاركة الشاشات وعرض عدة بثوث
للأستاذ في وقت واحد، مع تحكم بمفاتيح الطالب المحدد بعد موافقته. الواجهة عربية
بالكامل، والتطبيق لا يحتاج إنترنت في التشغيل العادي.

## تحميل أحدث نسخة
من صفحة [Releases](https://github.com/HusseinALEmara/Lab_show/releases) نزّل
`Lab show Setup 2.6.1.exe` وافتحه مباشرة؛ يبدأ التثبيت فوراً دون الحاجة للبحث داخل مجلد.
التحديث يغلق النسخة القديمة تلقائياً.

## التشغيل

- للتطوير: `npm start`
- لمعاينة الواجهة في المتصفح: `npm run preview` ثم افتح
  `http://127.0.0.1:4173/preview` (يشغّل خادم إشارات محلياً ويحقن خادماً وهمياً
  لخدمات Electron، لذلك تعمل البطاقات والتوليد تجريبياً).
- للاستخدام العادي: شغّل التطبيق المثبّت من قائمة Start أو سطح المكتب.
- لا تفتح `renderer/index.html` مباشرة في المتصفح؛ الواجهة تحتاج خدمات Electron
  المحلية (التقاط الشاشة، خادم الإشارات، شريط النظام).

## طريقة الاستخدام

### الأستاذ
1. من شاشة «أستقبل البثوث» افتح تبويب «توليد رمز»، واختر مدة الصلاحية ونوع الشبكة
   (المحلية هي الافتراضية، والعالمية اختيارية). لا يوجد عنوان للجلسة؛ عنوان كل بث يضعه صاحبه.
2. ولّد الرمز ونسخه، ثم زر «إنهاء صلاحية الرمز» عند الانتهاء.
3. في تبويب «البثوث الحالية» تظهر البثوث كقائمة أو بطاقات؛ اضغط أي بث لعرضه مع بقاء البقية ظاهرة.
4. داخل الفيديو: إيقاف مؤقت، تعويم فوق التطبيقات، وتكبير ملء الشاشة.
5. زر «مشاركة شاشتي أيضاً» يجعل هذا الجهاز باثّاً داخل نفس الجلسة.
6. أزرار التحكم بالمفاتيح لا تعمل إلا بعد سماح الطالب، وتُرسل للطالب المحدد فقط.

### الطالب
1. افتح «أبث شاشتي»، وأدخل رمز الأستاذ وعنوان بثك معاً (مثال: أحمد علي - مشروع التخرج).
   الاتصال المحلي هو الافتراضي؛ وللاتصال المباشر اختر «عنوان مباشر» وأدخل `IP:المنفذ`.
2. اضغط «موافقة». يظهر العنوان نفسه فوراً عند الأستاذ في بطاقة بثك.
3. بطاقة الحالة الصغيرة تعرض العنوان؛ اضغط عليه لتعديله فيُحدَّث لدى الأستاذ مباشرة.
4. فعّل «السماح بالتحكم بشاشتي» متى شئت، وأوقفه في أي وقت.
5. إيقاف مؤقت أو إيقاف نهائي متاح من البطاقة أو شريط النظام، والإيقاف المؤقت يلغي إذن التحكم.

تُرسل مفاتيح التنقل الأساسية فقط (الأسهم، إدخال، مسافة، خروج، جدولة، بداية/نهاية،
صفحة لأعلى/لأسفل)، بحد أقصى 12 ضغطة في الثانية. لا نصوص ولا اختصارات نظام.

## الهيكلة

```
main.js              عملية Electron: النوافذ، الشريط، IPC، دورة الحياة
preload.js           جسر آمن بين الواجهة والعملية الرئيسية
src/server.js        Express + Socket.IO + UDP للإشارات والاكتشاف المحلي
src/session-store.js منطق الجلسة الصرف (قابل للاختبار بدون شبكة)
src/session-fields.js تنقيح الرموز والعناوين والمدد
src/keyboard-controls.js  مفاتيح التحكم المسموح بها
src/app-lifecycle.js قواعد الإغلاق والتحديث
renderer/index.html  الواجهة الرئيسية
renderer/styles.css  التنسيق
renderer/app.js      منطق الواجهة والشبكة
renderer/floating.html المشغّل العائم
tests/               اختبارات الوحدة والتكامل
PLAN.md              خطة إعادة البناء وسجل التنفيذ
```

## الوضع العالمي والمطابقة
الوضع المحلي هو الافتراضي. للعمل عالمياً:
1. في تبويب «توليد رمز» اختر «الشبكة العالمية» وأدخل **اسماً فريداً**، ثم ولّد الرمز.
2. يظهر **رابط الجلسة العالمية** (يبدأ بـ `https://labshow.link/j?...`)؛ انسخه وأرسله للطالب.
3. الطالب يختار «مطابقة عالمية» ويدخل الرابط (ويُملأ الرمز واسم المستخدم تلقائياً)، فيتصل
   بجهاز الأستاذ مباشرة. لا يحتاج أي عنوان شبكة ولا خادماً وسيطاً.
4. الرابط يحمل رمز التحقق، ويُرفض أي انضمام باسم أو رمز غير مطابق، وينتهي بانتهاء الجلسة.
   **البث نفسه يبقى على جهاز المُبث**. للوصول من الإنترنت يحتاج جهاز الأستاذ إلى عنوان قابل
   للوصول؛ داخل الشبكة المحلية يعمل الرابط مباشرة.

## الاختبار والبناء

```bash
npm test        # 16 اختباراً: نموذج الجلسة، الخادم، التحكم، دورة الحياة
npm run check   # فحص صياغة كل ملفات JavaScript
npm run relay   # خادم مطابقة عالمي خفيف (لا يحمل البث)
npm run build   # إنشاء مثبّت Windows في dist/
```

المثبّت يغلق أي نسخة قديمة عبر الوسيط `--quit-for-update`، وإن كانت نسخة قديمة
لا تستجيب لهذا الوسيط فإنه ينهي عملية `Lab show.exe` قسراً قبل استبدال الملفات،
حتى لا يعلق المثبّت أو يظهر تنبيه «التطبيق يعمل بالفعل».
إغلاق النافذة الرئيسية أو الخروج من شريط النظام يوقف التطبيق وخادمه بالكامل.
