# Lab show

تطبيق سطح مكتب لمشاركة الشاشات واستقبالها داخل الشبكة المحلية أو عبر الإنترنت.
كل جهاز هو خادم بثوثه بنفسه: لا خادم مركزي ولا خادم وسيط خارجي. الواجهة بالعربية
والإنجليزية (زر تبديل اللغة أعلى الشاشة).

## تحميل أحدث نسخة
من صفحة [Releases](https://github.com/HusseinALEmara/Lab_show/releases) نزّل ملف
`Lab show Setup <الإصدار>.exe` وافتحه مباشرة. التحديث يغلق النسخة القديمة تلقائياً.

## الشاشة الرئيسية
مقسومة إلى قسمين يعملان معاً:

- **إرسال شاشتي:** أدخل رمز الجهاز المستقبِل ورابطه (الرابط اختياري داخل الشبكة
  المحلية؛ يُعثر على المستقبِل بالرمز وحده) وعنوان بثك، ثم «ابدأ الإرسال». يرسل الجهاز
  شاشته إلى جهة واحدة في كل مرة.
- **استقبال البثوث:** «توليد رمز» (محلي أو عالمي) يعطي رمزاً ورابطاً يرسلهما صاحبهما لمن
  سيرسل شاشته. تظهر البثوث الواردة بطاقات؛ اضغط «عرض» لعرض أي منها، مع إيقاف مؤقت وتعويم
  وتكبير. يستقبل الجهاز عدة بثوث معاً، ويستمر الاستقبال أثناء إرساله لشاشته.

التحكم بمفاتيح الجهاز المعروض (الأسهم، إدخال، مسافة، خروج، جدولة، بداية/نهاية، صفحة
لأعلى/لأسفل، 12 ضغطة في الثانية كحد أقصى) يعمل **داخل الشبكة المحلية فقط**، وبعد سماح
صاحب البث. وهو ممنوع في الوضع العالمي من الخادم والواجهة معاً.

## البث العمومي
لبث الشاشة لأكثر من شخص: «بدء بث عمومي» (محلي أو عالمي) يفتح نافذة جديدة فيها الرمز
والرابط. من يدخل الرمز والرابط في «الانضمام إلى بث عمومي» يدخل غرفة فيها:
بث صاحب الغرفة كفيديو، والتعليقات، وقائمة الحاضرين، والمايكروفون (الجميع يسمع الجميع:
صاحب البث يمزج الأصوات ويرسل لكل حاضر أصوات الآخرين). ولصاحب البث زر «منع الإشعارات
المنبثقة أثناء البث» (Windows)، تُعاد بعده الإعدادات كما كانت.
البث العمومي يُحسب الإرسالَ الوحيد للجهاز، فلا يُرسل الجهاز شاشته بشكل خاص أثناءه.

## الوضع العالمي (الإنترنت)
عند توليد رمز عالمي يطلب التطبيق من الراوتر فتح منفذ تلقائياً (UPnP)، ويضع العنوان العام
في الرابط، ويشغّل على الجهاز نفسه مُرحِّلاً (TURN) صغيراً لا يرحّل إلا إلى هذا الجهاز، فيصل
البث حتى حين يكون الطرفان خلف راوترين. إن كان UPnP معطلاً في الراوتر، أو كانت الشبكة خلف
ترجمة عناوين لدى مزود الخدمة (CGNAT)، تظهر رسالة واضحة بأن الرابط يعمل داخل الشبكة فقط.
يستخدم الاتصال خوادم STUN عامة لمعرفة العنوان فقط (لا تمر بها الصورة)؛ ويمكن استبدالها
بالمتغير `LABSHOW_STUN_URLS`.

## التشغيل والتطوير

```bash
npm start       # تشغيل التطبيق
npm run preview # معاينة الواجهة في المتصفح على http://127.0.0.1:4173/preview
npm test        # اختبارات الوحدة والتكامل
npm run check   # فحص صياغة كل ملفات JavaScript
npm run e2e     # التجربة الكاملة بالحاويات (Linux + Docker، بصلاحية root)
npm run build   # إنشاء مثبّت Windows في dist/
```

`npm run e2e` يبني «إنترنت» وهمياً وراوترين (أحدهما يدعم UPnP) وثلاثة أجهزة تشغّل
التطبيق الحقيقي على شاشات وهمية، ثم يتحقق من: الرابط العالمي والمنفذ المفتوح، وصول الشاشة
عبر راوترين، منع التحكم عالمياً، البث العمومي والتعليقات والأصوات، الشبكة المحلية والتحكم
فيها، وتبديل اللغة. انظر `tests/e2e/`.

## الهيكلة

```
main.js                 عملية Electron: النوافذ، شريط النظام، IPC، UPnP، الإشعارات
preload.js              جسر آمن بين الواجهة والعملية الرئيسية
src/server.js           خادم الجهاز: Socket.IO + UDP للاكتشاف المحلي + جلسات الاستقبال والبث العمومي
src/session-store.js    منطق جلسة الاستقبال (بلا شبكة)
src/room-store.js       منطق البث العمومي: الحاضرون والتعليقات والمايكروفونات
src/links.js            بناء روابط الجلسات وقراءتها (مشترك بين الخادم والواجهة)
src/upnp.js             فتح المنافذ في الراوتر (UPnP IGD)
src/turn-server.js      مُرحِّل TURN للجهاز نفسه (لا يرحّل إلا إليه)
src/notifications.js    إخفاء الإشعارات المنبثقة أثناء البث وإعادتها
src/session-fields.js   الرموز والعناوين والمدد
src/keyboard-controls.js مفاتيح التحكم المسموح بها
renderer/index.html     الشاشة الرئيسية (إرسال | استقبال)
renderer/room.html      نافذة البث العمومي
renderer/i18n.js        نصوص الواجهة بالعربية والإنجليزية
tests/                  الاختبارات، و tests/e2e للتجربة الكاملة بالحاويات
```
